## 👨‍💻 About Me

I'm **Arian Miraki**, a developer passionate about building modern, fast, and well-designed web experiences. I enjoy turning ideas into real products, from clean user interfaces to complete platforms.

- 🚀 Currently building **[ArianStack](https://github.com/arianmi7/arianstack)**, a platform that guides developers from learning code to landing real projects
- 🎨 Focused on **React**, **Tailwind CSS**, and modern front-end development
- 🐧 Comfortable with **Linux** (Debian-based, Arch-based, and Kali) and **Bash scripting**
- 🌐 Experienced with **networking** and network fundamentals
- 🔐 Exploring **cyber security** and secure development practices
- ⚙️ Working with **C++** and **Python**
- 🌍 Building products with full **Persian (RTL)** and English support
- 📚 Always learning, improving, and shipping
